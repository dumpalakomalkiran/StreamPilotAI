# Hackathon Submission Checklist

Confirm current rules and deadline at https://twitchcon-codex.devpost.com/.

- [ ] Project was newly built during the allowed submission period.
- [ ] Source repository, README, setup instructions, and any required license/attribution are ready.
- [ ] No keys, OAuth secrets, tokens, or private user data in Git.
- [ ] Hosted app works if a hosted URL is required.
- [ ] Public demo video is under three minutes.
- [ ] Video shows actual Twitch integration and Codex use.
- [ ] Gemini use and product features are accurately described.
- [ ] Primary Codex session ID captured using supported `/status`.
- [ ] Screenshots match the submitted application.
- [ ] Clean setup and tests are verified.
- [ ] Known limitations are disclosed honestly.
- [ ] Devpost form completed; final status says Submitted, not Draft.
- [ ] Submission confirmation saved.
